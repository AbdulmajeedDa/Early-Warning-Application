# Early Warning App | نظام الإنذار المبكر

نظام متكامل للإنذار المبكر من الزلازل والكوارث الطبيعية، يعمل على مدار الساعة لحماية المستخدم وعائلته. التطبيق موجه بشكل أساسي للمستخدمين في سوريا، ويوفر تنبيهات فورية، بيانات مباشرة عن الزلازل والطقس، ومركز إغاثة يربط المستخدمين بفرق الإنقاذ.

## المميزات

- **تسجيل الدخول والتسجيل**: بالبريد الإلكتروني (مع تحقق عبر OTP) أو بحساب Google.
- **تنبيهات فورية (Push Notifications)**: عبر Firebase Cloud Messaging، مع صوت إنذار (صفارة) مخصص حتى لو كان التطبيق مغلقًا.
- **الشاشة الرئيسية**: آخر الزلازل المسجلة، تحذيرات جوية، بيانات مباشرة من EMSC.
- **الطقس**: حالة الطقس في كل محافظات سوريا.
- **مركز الإغاثة**: إرسال طلب إغاثة وعرض فرق الإغاثة النشطة على الأرض.
- **الإبلاغات**: إرسال بلاغ ومتابعة سجل البلاغات وردود فريق العمل.
- **التعليمات الاحترازية**: إرشادات السلامة (قبل / أثناء / بعد) لكل نوع كارثة (زلازل، سيول، فيضانات، أعاصير، تسونامي).
- **محاكي الخطر**: أداة لاختبار جاهزية المستخدم وسرعة استجابته.
- **دعم لغتين**: العربية والإنجليزية، مع 3 سمات ألوان (داكن، ساطع، كلاسيكي).

## التقنيات المستخدمة

| الجزء | التقنية |
|---|---|
| الواجهة (Frontend) | Flutter (Dart) |
| الخادم (Backend) | Laravel (PHP) |
| الإشعارات | Firebase Cloud Messaging |
| تسجيل الدخول | Firebase Auth + Google Sign-In |
| تخزين آمن للتوكن | flutter_secure_storage |

## هيكل المشروع

```
lib/
  main.dart               # نقطة الدخول + كل شاشات التطبيق
  api_client.dart          # طبقة الاتصال بالـ API (REST) وتخزين التوكن
  google_auth.dart         # تسجيل الدخول بـ Google
  push_notifications.dart  # إعداد واستقبال إشعارات Firebase
android/
  app/src/main/kotlin/sy/earlywarning/app/   # الكود الأصلي (Native) لأندرويد
```

## طريقة التشغيل محليًا

1. ثبّت [Flutter SDK](https://flutter.dev).
2. `flutter pub get`
3. وصّل جهاز أندرويد حقيقي أو شغّل محاكي.
4. `flutter run`

للحصول على نسخة نهائية موقّعة للنشر:
```
flutter build apk --release --obfuscate --split-debug-info=<مسار خارج المشروع>
```

> ملاحظة: ملفات التوقيع (`key.properties`, `*.jks`) وأسرار الاتصال بالخادم مستثناة من المستودع عمدًا (`.gitignore`) ولا تُشارك علنًا.
